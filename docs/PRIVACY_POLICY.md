# BikeGoGo 隐私政策

更新日期：2026 年 7 月 28 日

生效日期：首次公开测试之日

BikeGoGo 是一款面向自行车骑行爱好者的骑行记录、Apple Watch 联动和好友小队语音
应用。本政策说明 BikeGoGo 如何处理你的信息。

## 1. 我们处理的信息

- 账户信息：访客设备标识、用户 ID、昵称、好友码；选择“通过 Apple 继续”时，还会
  处理 Apple 提供的账户标识，以及你选择提供的姓名和邮箱。
- 骑行与健康信息：骑行时间、距离、速度、轨迹、海拔、心率、卡路里和 Apple 健康
  中与骑行相关的数据。
- 位置信息：开始骑行后使用精确位置记录路线；允许后台定位时，锁屏或切换应用后仍会
  继续记录，直到暂停或结束骑行。你也可以主动选择向所在小队临时共享骑行位置和速度；
  该共享默认关闭，只有同一小队成员可以查看。主动发送小队紧急求助时，应用也会把
  当时的准确位置临时提供给同一小队的其他成员。
- 推送信息：APNs device token、App 推送环境和与 token 关联的用户 ID。
- 好友与小队信息：好友申请、好友关系、小队成员和语音房间所需的身份信息。

## 2. 麦克风与实时语音

麦克风仅在你主动加入小队语音后使用。音频通过 LiveKit 实时传输，BikeGoGo 后端不
录制语音，也不把语音内容保存到业务数据库。退出房间后，应用停止发送麦克风音频。

## 3. 使用目的

上述信息仅用于：

- 提供登录、好友、小队和消息通知功能；
- 记录、同步并展示骑行路线与统计数据；
- 联动 Apple Watch 开始户外单车训练并展示心率；
- 建立经好友或小队权限校验的实时语音；
- 在你主动开启时，向同一小队成员展示临时骑行位置；
- 在你二次确认发送紧急求助时通知小队成员并提供当时位置；
- 保障账户与接口安全、诊断服务故障。

BikeGoGo 不使用这些信息进行跨应用跟踪，也不出售个人信息或健康数据。

## 4. 信息共享与服务提供商

为提供核心功能，部分信息会由以下服务处理：

- Apple：通过 Sign in with Apple、HealthKit 和 Apple Push Notification service
  提供登录、健康数据与推送能力；
- LiveKit Cloud：为小队成员传输实时音频；
- BikeGoGo 后端：在项目自有服务器和 PostgreSQL 数据库中保存账户、好友、小队、
  推送 token 与同步的骑行数据。

除提供上述功能、遵守法律义务或保护用户安全所必需的情况外，我们不会向其他第三方
披露你的个人信息。

## 5. 保存与删除

骑行、账户和好友数据会保存到你删除对应数据或提出账户删除请求为止。退出登录会删除
当前设备上的会话并解绑推送 token，但不会自动删除云端账户与历史。你可以在应用内
删除单条云端骑行记录。正式发布前，我们会提供账户删除入口；在此之前可通过本政策
末尾联系方式提交删除请求。

小队实时位置只在服务端内存中短暂保存。停止共享、结束骑行、退出或被移出小队时会
清除；最后一次更新超过 90 秒也会自动过期。该临时位置不会写入 PostgreSQL 或 JSON
备份。紧急求助会通过 APNs 向同一小队成员发送求助人、小队和临时坐标；坐标仍遵循
90 秒过期规则，但接收者可能在收到通知后自行联系或查看位置。已经完成的骑行路线仍
按上述骑行数据规则保存。

## 6. 权限控制

你可以随时在 iPhone 或 Apple Watch 的“设置”中关闭定位、麦克风、通知或健康权限。
关闭权限会影响对应功能，但不会影响与该权限无关的基础功能。

## 7. 安全

客户端通过 HTTPS 与 BikeGoGo 后端通信；实时语音使用加密传输。访问令牌和服务端
密钥不会写入公开客户端代码。我们会采取合理的技术和管理措施保护数据，但任何网络
传输或存储都无法保证绝对安全。

## 8. 未成年人

BikeGoGo 不面向未满适用地区法定年龄的儿童。若发现未经监护人同意处理了儿童信息，
请联系我们删除。

## 9. 政策变更

功能或数据处理方式发生实质变化时，我们会更新本政策及更新日期，并在适当情况下在
应用内提示。
